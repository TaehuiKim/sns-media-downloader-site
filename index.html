어떤 링크를 사용할 수 있나요?

Instagram 게시물·릴스, X 게시물, Threads 게시물 링크를 입력할 수 있습니다. 사이트의 공개 응답에 원본이 없거나 요청이 제한되면 추출에 실패할 수 있습니다.

비공개 계정도 다운로드할 수 있나요?

웹 버전은 비공개 게시물이나 로그인이 필요한 콘텐츠에 접근하지 않습니다. SNS 비밀번호와 로그인 쿠키를 요청하지 않습니다.

영상과 여러 장의 사진도 지원하나요?

공개 데이터에 직접 MP4 주소나 이미지 원본이 있으면 선택할 수 있습니다. HLS·DASH 영상 변환은 지원하지 않으며 모든 게시물의 추출을 보장하지 않습니다.

파일이나 게시물 링크를 저장하나요?

미디어 파일을 서버에 보관하지 않습니다. 입력한 URL은 처리 목적으로 Supabase 서버와 해당 SNS로 전송되며, 호스팅 서비스는 보안·운영 로그를 처리할 수 있습니다. 자세한 내용은 웹 서비스 개인정보 안내를 확인하세요.

왜 Anvel 로그인이 필요한가요?

테스트 서비스의 사용 권한을 확인하기 위한 로그인입니다. SNS 계정과는 별개이며, 현재 결제나 구독을 청구하지 않습니다.
