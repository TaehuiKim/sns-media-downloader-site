사용 방법

  1. 지원 SNS에서 본인 소유 또는 저장 권한이 있는 게시물을 엽니다.
  2. 미디어 위에 마우스를 올리거나 Tab으로 다운로드 버튼을 선택합니다.
  3. 여러 항목은 선택 창에서 원하는 것만 고른 뒤 다운로드합니다. 단일 항목은 바로 저장합니다.
  4. 하단 상태 알림과 Chrome 다운로드 목록에서 저장 결과를 확인합니다.

버튼이 없거나 저장이 실패하나요?

  • 확장 프로그램의 해당 사이트 접근 권한을 확인하고 페이지를 새로고침하세요.
  • 영상 원본 URL이 아직 수집되지 않았다면 잠시 재생한 뒤 다시 시도하세요.
  • 주소 만료·접근 거부는 로그인 상태와 해당 게시물 접근 가능 여부를 확인한 뒤 새로고침하세요.
  • HLS/DASH 전용 스트림, DRM, 삭제·접근 제한된 콘텐츠 및 일부 SNS 화면은 지원하지 않습니다.

문제 신고

Chrome 버전, 확장 프로그램 버전, 사이트 종류, 재현 단계, 실제 표시된 오류를 지원 이메일로 알려주세요. 회신 시간을 보장하는 유료 지원 서비스는 아닙니다.

계정 비밀번호, 인증 쿠키, 개인 메시지 또는 서명된 미디어 URL은 보내지 마세요. 스크린샷은 개인정보를 가린 뒤 첨부하세요.

삭제

Chrome 확장 관리 화면에서 삭제할 수 있습니다. 이미 다운로드한 파일과 Chrome 자체 기록은 별도로 삭제해야 합니다.
