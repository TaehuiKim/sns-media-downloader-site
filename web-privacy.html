확장 프로그램과 웹 서비스의 차이

웹 다운로더는 서버에서 공개 게시물을 읽습니다. 브라우저 안에서 처리하는 확장 프로그램의 개인정보처리방침과 적용 범위가 다릅니다.

계정과 결제

Google OAuth와 Supabase Authentication으로 로그인하며 Google이 허용한 기본 프로필, 이메일과 사용자 ID를 처리합니다. 인증 세션과 갱신 토큰은 이 사이트의 브라우저 로컬 저장소에 유지됩니다. 로그아웃하면 저장된 세션이 삭제됩니다. 브라우저 저장소를 지워도 서버 계정과 결제 기록은 자동 삭제되지 않습니다.

웹사이트와 확장 프로그램은 같은 Google 계정의 공통 이용권을 사용합니다. 인증 토큰을 Supabase에 보내 권한을 확인하고, 사용자 ID, Paddle 거래·고객·가격·구독 ID, 결제 기간, 환불·이벤트 상태를 서버에 보관합니다. Paddle 결제창과 결제 제공자는 결제·청구 정보를 처리하며 개발자는 카드 번호를 별도 저장하지 않습니다. Paddle.js는 결제를 시작할 때만 공식 CDN에서 로드합니다. Google 비밀번호나 SNS 로그인 쿠키를 이 사이트에 입력하지 마세요.

미디어 처리

미디어 찾기를 누르면 입력한 SNS URL을 Supabase Edge Functions로 보냅니다. 서버는 해당 SNS에 공개 페이지를 요청하고 이미지·영상 URL을 반환합니다. 파일 자체를 데이터베이스나 Storage에 저장하지 않습니다. 미리보기와 저장 요청 시 브라우저는 SNS 미디어 CDN에 직접 접속하므로 CDN은 IP 주소 등 요청 정보를 처리할 수 있습니다.

호스팅 및 로그

웹 페이지는 GitHub Pages, 인증과 URL 처리는 Supabase가 제공합니다. 각 호스팅 서비스는 요청 IP 주소, 요청 시각, 경로, 오류·보안 로그 등을 서비스 정책과 프로젝트 설정에 따라 처리할 수 있습니다. 애플리케이션은 게시물 URL이나 미디어 정보를 별도 영구 기록하지 않습니다. 별도 분석·광고 스크립트는 사용하지 않습니다.

보관 및 삭제

미디어 결과는 페이지 메모리에 유지됩니다. 인증 세션은 로그아웃하거나 브라우저 저장소를 지울 때까지 유지할 수 있습니다. 계정과 이용권 정보는 서비스 제공에 필요한 동안 보관하며, 결제 제공자의 기록에는 해당 보관 정책과 적용되는 보관 의무가 따릅니다. 계정 삭제 요청은 지원 이메일로 보내주세요. 호스팅 업체의 운영 로그에는 업체별 보관 기간이 적용됩니다.

제한

SNS 로그인 비밀번호, 세션 쿠키, 개인 메시지 등을 입력하지 마세요. 비공개·유료·DRM 콘텐츠 접근 우회 기능은 제공하지 않습니다. 구매 버튼만으로 결제가 완료되지 않습니다. Paddle 결제창에서 표시하는 가격·갱신 조건을 확인하고 결제를 완료하면 서버 검증을 거쳐 이용권을 활성화합니다. 결제 서비스가 아직 설정되지 않은 경우 구매 버튼은 비활성화됩니다.
