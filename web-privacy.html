확장 프로그램과 웹 서비스의 차이

웹 다운로더는 서버에서 공개 게시물을 읽습니다. 브라우저 안에서 처리하는 확장 프로그램의 개인정보처리방침과 적용 범위가 다릅니다.

처리하는 정보와 목적

Anvel 로그인 시 이메일과 비밀번호가 Supabase Authentication으로 전송되어 인증됩니다. 이 웹사이트는 비밀번호를 별도로 저장하지 않습니다. 인증 토큰은 페이지 메모리에만 유지되며 새로고침하면 다시 로그인해야 합니다. 운영자는 Supabase 관리 화면에서 테스트 계정의 이메일과 인증 상태를 관리할 수 있습니다.

미디어 찾기를 누르면 입력한 SNS URL을 Supabase Edge Functions로 보냅니다. 서버는 해당 SNS에 공개 페이지를 요청하고 이미지·영상 URL을 반환합니다. 파일 자체를 데이터베이스나 Storage에 저장하지 않습니다. 미리보기와 저장 요청 시 브라우저는 SNS 미디어 CDN에 직접 접속하므로 CDN은 IP 주소 등 요청 정보를 처리할 수 있습니다.

호스팅 및 로그

웹 페이지는 GitHub Pages, 인증과 URL 처리는 Supabase가 제공합니다. 각 호스팅 서비스는 요청 IP 주소, 요청 시각, 경로, 오류·보안 로그 등을 서비스 정책과 프로젝트 설정에 따라 처리할 수 있습니다. 애플리케이션은 게시물 URL이나 미디어 정보를 별도 영구 기록하지 않습니다. 별도 분석·광고 스크립트는 사용하지 않습니다.

보관 및 삭제

결과와 토큰은 페이지 메모리에 유지되며 페이지를 닫거나 새로고침하면 사라집니다. 테스트 계정은 테스트 접근 권한 관리에 필요한 동안 유지합니다. 계정 삭제 요청은 지원 이메일로 보내주세요. 호스팅 업체의 운영 로그에는 업체별 보관 기간이 적용됩니다.

제한

SNS 로그인 비밀번호, 세션 쿠키, 개인 메시지 등을 입력하지 마세요. 비공개·유료·DRM 콘텐츠 접근 우회 기능은 제공하지 않습니다. 현재 결제는 받지 않으며 가격이나 구독을 자동 청구하지 않습니다.
