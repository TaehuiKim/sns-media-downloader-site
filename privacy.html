미디어 처리는 브라우저에서.
계정과 공통 이용권은 Supabase로 확인합니다.

운영자: Anvel · 시행일: 2026-10-21 · Read in English ↓

이 방침은 Chrome 확장 프로그램 SNS Media Downloader에 적용됩니다. URL을 서버에서 처리하는 웹 다운로더와 웹 결제에는 웹 서비스 개인정보 안내가 추가로 적용됩니다.

1. 미디어와 다운로드

지원 SNS의 DOM, 초기 JSON, fetch/XHR 응답에서 사진·영상 URL, 미디어·게시물 ID, 작성자 사용자명, 화질 정보를 추출합니다. API 응답에는 다른 게시물 정보가 포함될 수 있으나 관련 미디어 식별에만 사용합니다. 미디어 정보는 탭 메모리에 유지하고 개발자 서버로 전송하거나 영구 기록하지 않습니다. 주요 레지스트리는 최대 1,000개이며 접근·갱신 시 30분이 지난 항목을 정리합니다. 탭을 닫거나 새로고침하면 사라집니다.

선택한 URL과 파일명은 Chrome 다운로드 API로 전달합니다. 확장 프로그램이 시작한 다운로드의 ID·상태·오류만 확인합니다. 다운로드 임시 상태는 완료·중단 또는 서비스 워커 종료 시 정리합니다. 저장 파일과 Chrome 자체 기록은 사용자가 별도로 삭제합니다.

2. Google 로그인과 이용권

Google OAuth와 Supabase Authentication으로 로그인합니다. Google에서 허용한 기본 프로필, 이메일, 사용자 ID가 인증 과정에서 처리됩니다. Google 비밀번호를 확장 프로그램에 입력하지 않습니다. 세션·갱신 토큰과 사용자 정보는 Chrome 로컬 저장소에 유지해 로그인을 지속하며 SNS 콘텐츠 스크립트가 접근할 수 없도록 제한합니다. Chrome 동기화 저장소는 사용하지 않습니다.

다운로드 전에 Supabase에 인증 토큰을 전송해 구매 권한을 확인합니다. 서버는 사용자 ID, Paddle 거래·고객·가격·구독 ID, 이용 기간, 환불·이벤트 처리 상태를 보관합니다. 인증이나 결제 확인 요청에 SNS 게시물 주소나 미디어 URL은 포함하지 않습니다.

3. Paddle 결제

구매 버튼은 웹사이트를 열어 Paddle 결제창으로 안내합니다. 결제 정보와 결제 수단은 Paddle 및 결제 제공자가 처리하며 개발자는 카드 번호를 별도 저장하지 않습니다. 서명 검증된 결제 이벤트를 서버에서 확인한 후 공통 이용권을 활성화합니다. 환불 승인 시 해당 거래의 이용권을 해제하며, 구독 해지·갱신 실패 시 이미 결제한 기간이 끝나면 이용권이 만료됩니다.

4. 권한과 외부 서비스

  • downloads: 선택 파일 저장과 해당 다운로드의 상태 확인.
  • storage: 로그인 세션 유지. 게시물·다운로드 이력을 저장하지 않습니다.
  • identity: Google OAuth 로그인 창과 인증 콜백 처리.
  • 지원 SNS 호스트: 다운로드 버튼 및 미디어 매칭.
  • 프로젝트 Supabase 호스트: 인증·세션 갱신과 이용권 확인.

Google, Supabase, Paddle, SNS/CDN 및 GitHub Pages는 각 서비스 제공 과정에서 IP 주소와 요청 메타데이터 등을 자체 정책에 따라 처리할 수 있습니다. 확장 프로그램은 원격 실행 코드, 광고, 분석 SDK, cookies/history 권한을 사용하지 않습니다. 모든 확장 JavaScript는 설치 패키지에 포함됩니다. 웹사이트의 Paddle.js는 웹 결제에서만 로드합니다.

5. 보관·선택·삭제

로그아웃하면 저장된 인증 세션을 삭제합니다. 확장 프로그램 삭제로 로컬 저장소를 제거할 수 있으나 서버 계정·결제 기록은 자동 삭제되지 않습니다. 계정 정보는 서비스 제공에 필요한 동안 유지합니다. 계정 삭제·개인정보 문의는 taehuikim@caleup.ai로 요청하세요. 결제 제공자의 거래 기록과 운영 로그에는 해당 업체의 보관 정책 및 적용되는 보관 의무가 따릅니다. 문의 이메일과 자발적으로 제공한 내용은 지원 목적으로 처리합니다.

Privacy policy

Operator: Anvel. Effective date: 2026-10-21. Contact: taehuikim@caleup.ai.

The extension processes SNS page DOM and JSON in tab memory to identify media URLs, authors, IDs and quality. It submits selected files to Chrome Downloads and tracks only downloads it initiates. Main media registries hold at most 1,000 entries with a 30-minute expiry checked on access. Tab close/refresh clears extracted metadata; temporary download state is removed on completion, interruption or worker shutdown. SNS URLs and media data are not sent to our authentication or billing backend.

Google OAuth and Supabase Auth process basic profile information, email and user IDs. Sessions and refresh tokens are stored in Chrome local storage, restricted to trusted extension contexts. Supabase verifies paid access and stores user, Paddle transaction/customer/price/subscription identifiers, paid periods and refund/event status. Paddle and its payment providers process payments; we do not separately store card numbers. Paddle checkout runs on our website, not as remote code in the extension. Approved refunds revoke the related grant. Cancellation or failed renewal does not extend the previously paid period.

The extension uses downloads, storage and identity permissions, supported SNS host access and the project's Supabase host access. It uses no advertising/analytics SDK, remote executable code, cookies permission or browsing-history permission. Third-party services may process request metadata under their policies. Log out to clear stored sessions, uninstall to remove extension local data, and contact support for server-account deletion. Account and billing records remain as needed for service, applicable retention obligations and providers' policies. Saved files and Chrome download history are managed separately by you. See our web privacy notice for the website and web downloader.
