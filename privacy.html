미디어를 찾는 처리는 브라우저 안에서.
개발자의 서버로 게시물이나 파일을 업로드하지 않습니다.

운영자: Anvel · 시행일: 2026-10-19 · Read in English ↓

이 방침은 Chrome 확장 프로그램 SNS Media Downloader와 본 안내 웹사이트에 적용됩니다. 외부 전송이 없다는 것은 개발자 서버로 수집·전송하지 않는다는 뜻입니다. 사용자의 브라우저는 기능 제공을 위해 SNS 사이트 및 해당 미디어 CDN과 통신합니다.

1. 어떤 정보를 처리하나요?

지원 사이트(X/Twitter, Instagram, Threads)에 접속한 동안 페이지의 DOM, 초기 JSON과 fetch/XHR API 응답을 메모리에서 분석합니다. 이미지·영상 URL, 미리보기 URL, 미디어/게시물 ID, 작성자 사용자명 및 화질 정보를 미디어 매칭과 파일명 생성에 사용합니다. API 응답에는 게시물의 다른 정보가 포함될 수 있으나, 관련 미디어 메타데이터를 추출하기 위한 용도로만 분석하며 별도 영구 기록을 만들지 않습니다.

다운로드를 누르면 선택한 URL·파일명으로 Chrome 다운로드 API를 호출합니다. 확장 프로그램이 시작한 다운로드의 ID, 상태, 오류를 확인해 접수·저장 완료·실패를 표시합니다. 다른 다운로드의 목록을 일괄 수집하지 않습니다.

2. 사용하지 않는 정보와 기능

  • 자체 회원가입, 광고, 분석 SDK, 추적 픽셀 및 개발자 운영 백엔드가 없습니다.
  • 비밀번호·세션 쿠키를 직접 읽거나 저장하지 않으며 cookies 권한을 요청하지 않습니다.
  • 지원 사이트 밖의 방문 기록을 조회하지 않으며 history 권한을 요청하지 않습니다.
  • 확장 프로그램의 로컬/동기화 저장소에 게시물이나 다운로드 기록을 보관하지 않습니다.

3. 보관 기간과 삭제

추출한 미디어 정보는 해당 탭의 메모리에만 보관합니다. 각 주요 레지스트리는 최대 1,000개이고, 접근·갱신 시 30분이 지난 항목을 정리합니다. 탭 종료 또는 새로고침 시 사라집니다. 다운로드 상태 확인용 임시 정보는 완료·중단 시 정리하거나 서비스 워커 종료 시 사라집니다.

저장된 파일과 Chrome 자체의 다운로드 기록은 Chrome 및 사용자가 관리합니다. 확장 프로그램을 삭제해도 이미 저장한 파일은 삭제되지 않습니다. 파일은 기기의 파일 관리자로, 다운로드 기록은 Chrome 다운로드 화면에서 직접 삭제할 수 있습니다.

4. 외부 제공과 네트워크

개발자는 확장 프로그램의 미디어 정보나 다운로드 내역을 수신·판매·광고 제공·제3자에게 전송하지 않습니다. SNS와 CDN은 페이지 표시, 미리보기, 파일 다운로드를 위해 요청을 받으며 브라우저 동작에 따라 IP 주소·기기/요청 정보·기존 로그인 상태 등을 처리할 수 있습니다. 해당 처리는 각 서비스의 정책을 따릅니다. 이 확장 프로그램은 미디어 변환을 외부 서버에 맡기지 않습니다.

Privacy policy

Operator: Anvel. Effective date: 2026-10-19. Contact: taehuikim@caleup.ai.

Information processed

While you visit supported X/Twitter, Instagram and Threads pages, the extension inspects page DOM, initial JSON and fetch/XHR responses in browser memory to extract media URLs, previews, post/media IDs, author usernames and quality details. Responses may contain other page content; they are parsed to identify relevant media and are not kept in a separate permanent record. When you choose to download, the extension submits selected URLs and filenames to Chrome and monitors the IDs, states and errors of downloads it initiates.

Storage and retention

Extracted metadata remains in tab memory. Each main registry holds at most 1,000 entries with a 30-minute expiry checked on access or updates. Closing or refreshing the tab clears it. Temporary download tracking is removed on completion/interruption or worker shutdown. No extension local/sync database is used. Saved files and Chrome's own download history remain under your control, including after uninstalling the extension.

Sharing and third parties

The developer does not receive, sell, or transmit extension media data to advertising, analytics or developer servers. There is no developer backend, tracking SDK, account system or external media conversion service. Your browser still contacts SNS sites and their media CDNs for normal page, preview and download requests. These services may process your IP address, request details and existing browser login state under their own policies. Passwords or session cookies are not directly read or stored by the extension. It does not request cookies or browsing history permissions.

Permissions and choices

The downloads permission saves selected files and checks their state; access to supported SNS sites enables media identification and download buttons. You may cancel a selection, restrict site access, disable or uninstall the extension, and delete files and download records yourself.

Support and this website

If you contact support, we process your email and voluntarily supplied report only as needed to respond, deleting information no longer needed after resolution except where retention is required by law. Public GitHub issues are public: do not include credentials, signed URLs or private messages. This static website uses no analytics or additional cookies; GitHub Pages may process hosting request information under GitHub's privacy statement. This policy and its effective date will be updated when practices change.
